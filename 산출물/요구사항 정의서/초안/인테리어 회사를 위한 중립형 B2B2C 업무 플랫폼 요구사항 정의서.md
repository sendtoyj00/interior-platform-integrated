# 인테리어 회사를 위한 중립형 B2B2C 업무 플랫폼 요구사항 정의서

## 1. 서비스 개요

### 1.1 서비스명
인테리어 회사를 위한 중립형 B2B2C 업무 플랫폼

### 1.2 서비스 목적
인테리어 업체가 고객관리부터 견적, 계약, 시공관리, 고객 알림까지 필요한 업무 기능을 선택하여 사용할 수 있도록 제공하고, 고객은 업체가 공유한 프로젝트에 참여하여 공사 진행 정보를 확인할 수 있는 중립형 업무 플랫폼을 구축한다.

### 1.3 핵심 가치

- **업체:** 필요한 업무 모듈만 선택하여 반복 업무를 줄인다.
- **고객:** 견적·계약·공정·사진 등 자신의 공사 정보를 한곳에서 확인한다.
- **플랫폼:** 특정 인테리어 업체에 종속되지 않고 여러 업체가 독립적으로 사용할 수 있는 환경을 제공한다.

## 5. 핵심 업무 흐름

### 업체 측

업체 가입  
→ 워크스페이스 생성  
→ 필요한 모듈 선택  
→ 고객 문의 등록  
→ 상담 진행  
→ 견적 생성  
→ 고객 공유  
→ 계약 확정  
→ 프로젝트 생성  
→ 공정 등록  
→ 고객 알림  
→ 공사 완료  
→ 리뷰 요청

### 고객 측

프로젝트 초대  
→ 프로젝트 참여  
→ 견적 확인  
→ 변경 견적 확인  
→ 계약 확인  
→ 공정 확인  
→ 현장 사진 확인  
→ 완료 알림  
→ 리뷰 작성

## 6. 모듈 구성

플랫폼의 차별화 요소인 **선택형 모듈**은 다음과 같이 구성한다.

| 모듈 | 주요 기능 |
|---|---|
| 문의관리 | 문의 등록, 상담 상태, 고객정보 |
| 견적관리 | 공사항목, 자재, 단가, 견적서 |
| 계약관리 | 계약 정보, 계약 상태, 변경 이력 |
| 프로젝트관리 | 공사기간, 담당자, 현장정보 |
| 공정관리 | 공정 단계, 진행률, 작업내용 |
| 현장관리 | 현장 사진 및 작업기록 |
| 고객관리 | 고객 초대, 프로젝트 공유 |
| 알림관리 | 카카오 알림톡 및 시스템 알림 |
| 리뷰관리 | 완료 처리, 리뷰 요청 |

업체는 예를 들어 **견적관리 + 프로젝트관리 + 공정관리**만 사용할 수도 있고, 전체 모듈을 활성화하여 End-to-End로 사용할 수도 있다.

## 8. 핵심 차별점

본 서비스는 특정 인테리어 업체를 연결하거나 직접 시공 서비스를 제공하는 것이 아니라, **여러 인테리어 회사가 각자의 고객과 프로젝트를 독립적으로 운영할 수 있는 중립적인 업무 플랫폼**을 목표로 한다.

특히 다음 구조를 핵심 차별점으로 한다.

**중립 플랫폼**
→ **업체별 독립 워크스페이스**
→ **필요한 모듈만 선택**
→ **업체가 자기 고객을 직접 관리**
→ **고객은 해당 프로젝트에만 참여**

따라서 서비스의 핵심 요구사항은 단순한 인테리어 CRM이 아니라 **“멀티테넌트 + 모듈형 + B2B2C 프로젝트 관리”​**로 정의한다.

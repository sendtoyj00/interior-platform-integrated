## 1. 서비스 개요

### 1.1 서비스 목적

인테리어 업체가 고객 문의부터 견적, 시공 진행, 고객 알림까지 반복되는 업무를 AI 기반 자동화로 줄이고, 고객은 공유받은 링크를 통해 자신의 공사 정보(견적·공정·사진)를 언제든 확인할 수 있는 B2B2C 업무 플랫폼을 구축한다.

### 1.2 핵심 가치 (정체성)

| 이해관계자 | 핵심 가치                                                             |
| ---------- | --------------------------------------------------------------------- |
| 업체       | 문의 접수부터 시공까지 반복 업무를 AI와 자동화로 줄인다               |
| **고객**   | **자기 공사 정보(견적·진행상황·사진)를 언제든 웹에서 확인할 수 있다** |
| 플랫폼     | 고객은 별도 회원가입 없이 초대 링크만으로 쉽게 참여할 수 있다         |

> 본 서비스는 **업체와 고객이 함께 쓰는 B2B2C 플랫폼**임을 전제로 모든 요구사항을 설계한다. 이 전제가 지켜지지 않으면 서비스의 핵심 차별점이 성립하지 않는다.

### 1.3 이해관계자

| 이해관계자           | 역할                    | 주요 요구                          |
| -------------------- | ----------------------- | ---------------------------------- |
| 인테리어 업체 담당자 | 문의·견적·프로젝트 관리 | 반복 업무 자동화, 고객 응대 효율화 |
| 인테리어 고객        | 프로젝트 정보 조회      | 로그인 없이 견적·공정·사진 확인    |
| 외부 알림 API        | 고객 알림 제공          | 카카오 알림톡 발송                 |

## 2. 기능 요구사항 (Functional Requirements)

| 요구사항 ID | 대분류   | 요구사항명                    | 상세 요구사항 내용                                                                                                                  | 중요도 | 난이도 | 관련 화면 ID                |
| ----------- | -------- | ----------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- | ------ | ------ | --------------------------- |
| REQ-F-001   | 회원     | 업체 회원가입 및 로그인       | 인테리어 업체 담당자가 이메일/비밀번호로 가입하고 로그인할 수 있어야 한다. 가입 시 회사명, 담당자명을 함께 등록한다.                | High   | 하     | SCR-AUTH-001                |
| REQ-F-002   | 문의     | 고객 문의 등록 및 AI 자동분류 | 고객 문의(공사유형, 평수, 예산, 연락처)를 등록하면 AI가 문의 내용을 분석해 공사유형별 카테고리를 자동 태깅하고 담당자에게 배정한다. | High   | 중     | SCR-DASH-001                |
| REQ-F-003   | 견적     | 견적 생성 및 고객 공유        | 담당자가 공사항목·수량·단가를 입력해 견적서를 생성하고, 생성된 견적서를 고유 링크로 고객에게 공유할 수 있어야 한다.                 | High   | 중     | SCR-EST-001                 |
| REQ-F-004   | 프로젝트 | 프로젝트 생성 및 공정 관리    | 견적 확정 시 프로젝트가 생성되며, 담당자가 공정 단계(철거/설비/마감 등)와 현장 사진을 등록해 진행상태를 관리할 수 있어야 한다.      | High   | 중     | SCR-PROJ-001                |
| REQ-F-005   | 알림     | 고객 자동 알림 발송           | 견적 공유, 공정 단계 업데이트 발생 시 카카오 알림톡 API를 통해 고객 조회 링크를 포함한 알림을 자동 발송한다.                        | Medium | 하     | SCR-PROJ-001 → SCR-CUST-001 |
| REQ-F-006   | 고객     | 고객 프로젝트 조회            | 고객이 공유받은 고유 링크로 별도 로그인 없이 접속해, 자신의 견적·공정단계·현장사진을 조회할 수 있어야 한다.                         | High   | 중     | SCR-CUST-001                |

## 5. 핵심 업무 흐름

### 업체 측

업체 가입 → 로그인 → 고객 문의 등록 → AI 자동분류·담당자 배정 → 견적 생성 → 고객 공유(링크 발급) → 계약 확정·프로젝트 생성 → 공정 등록·사진 업로드 → 고객 알림 발송 → 공사 완료

### 고객 측

알림톡 수신(링크 포함) → 링크 클릭(로그인 없이 접속) → 견적 확인 → 공정 진행상황 확인 → 현장 사진 확인

## 6. 데이터 모델 (ERD 요약)

| 테이블    | 주요 컬럼                                                   |
| --------- | ----------------------------------------------------------- |
| companies | id, name, created_at                                        |
| users     | id, company_id, email, password, role                       |
| inquiries | id, company_id, category(AI분류결과), space, budget, status |
| estimates | id, inquiry_id, amount, share_token                         |
| projects  | id, estimate_id, status, access_token, photos               |

> `access_token`(estimates), `access_token`(projects) 두 컬럼이 REQ-F-003·REQ-F-006(고객 링크 접근)을 구현하는 핵심 장치이며, 별도의 고객 인증 테이블 없이 B2B2C 정체성을 구현한다.
